### Formatting Rules

- Use **bold** for numbers, magical terms, or key points.
- Use `-` or `1.` for lists.
- Use `> blockquotes` for important findings or wise sayings.
- Use `` `inline code` `` for short technical terms or numbers like ean or the itscope-id.
- Do **not** overuse formatting.
- Do **not** output:
    - HTML tags
    - Code fences
    - Wrapping containers
    - Explanatory text about these rules
